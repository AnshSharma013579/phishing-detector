What is this project?

Phishing Email & Link Detector is a rule-based cybersecurity tool that helps you identify phishing emails and malicious URLs without relying on any machine-learning model. Every decision is fully transparent — you can see exactly which rules fired and why.

📧

Email Analysis

Paste raw email content or upload a .eml file. The engine checks sender domains, header spoofing, urgency keywords, sensitive data requests, HTML-only structure, and dangerous attachments across 8 rules.

🔗

Link / URL Analysis

Paste any URL to inspect it for typosquatting, homograph attacks, suspicious TLDs, IP-based hosts, URL shorteners, redirect chains, and more across 13 rules.

🧮

Confidence Scoring

Every scan returns a raw score (points from triggered rules), a max possible score, and a confidence % — how certain the engine is in its verdict. Higher score = higher confidence of a threat.

🌐

API Threat Intelligence

When API keys are configured, URLs are cross-checked against PhishTank (community-verified phishing database) and VirusTotal (70+ antivirus engines). Hits add extra weight to the score.

🗄️

Scan History

Every analysis is automatically logged to a local SQLite database with the mode, verdict, score, and timestamp — giving you a full audit trail of past scans.

🔍

Rule Transparency

Unlike black-box ML models, every verdict comes with a full breakdown of which rules triggered, their severity level, and exactly what was found — so you always know why an email was flagged.

Technology Stack

Python 3 Flask NLTK Regex / NLP SQLite VirusTotal API PhishTank API HTML / CSS / JS

Pattern references: Anti-Phishing Working Group (APWG · apwg.org) and PhishTank (phishtank.org) community database.

How to run

pip install -r requirements.txt
python app.py
# → open http://127.0.0.1:5000

To enable live API checks, add your free keys to config.py:

VIRUSTOTAL_API_KEY = "..."   # virustotal.com/gui/join-us
PHISHTANK_API_KEY  = "..."   # phishtank.com/api_register.php
